AIGM in 30 Seconds (Human-Friendly Intro)

AIGM helps humans and AI collaborate with maximum clarity and minimum chaos.
It is built around three human-facing values:

1. Truth – work with reality, not politics.
2. Freedom – participation is voluntary; no pressure, no fear.
3. Joy – people create best when they feel good.

These values orient how AIGM is explained and used by people. They are not a separate technical architecture layer.

AIGM gives:
- clearer roles
- fair recognition (merit)
- safer teamwork
- less drama and confusion

This is Layer 0 of AIGM: a simple, human explanation before any structure or rules.

# AIGM Standard

A lightweight, human-readable governance and collaboration model
for teams, individuals, and AI-assisted systems.

---

## Human-Facing Values

Truth, Freedom and Joy are the human-facing values of AIGM.

They are orientation values, not a separate normative enforcement layer. Normative requirements are defined directly in AIGM Core, governance rules, domain standards and technical invariants.

---

## AIGM Core – What the Standard Is

AIGM Core defines how responsibility, skill, trust, validation and decision-making scale.

It exists to:
- make collaboration efficient,
- reward real skill instead of titles,
- maintain discipline without bureaucracy,
- prevent drift into politics, favoritism or chaos,
- define implementation-neutral safety and conformance invariants.

It is not a political movement, religion, power elite or mandatory software architecture.

---

## Tier Hierarchy (Human View)

- **Tier-∞** – Origin. Identifies Tier-1337 actors and protects AIGM standard integrity; does not control domain content unless it violates AIGM invariants.
- **Tier-1337** – Domain standard definers and maintainers. Define domain standards and certification requirements.
- **Tier-1** – Validators / certifiers and lead implementers. Perform normal validation against Tier-1337 requirements.
- **Tier-2** – Practical solvers / builders.
- **Tier-3** – Observers / feedback contributors.
- **Tier-4** – Unsynced public layer.

Higher tier means stronger validated competence and greater responsibility, not universal command authority.

---

## Core Rules

- Proof before merit.
- Tier is competence, not general power.
- Promotion uses the general three-validation rule for promotable tiers.
- Tier-1337 defines domain standards and certification requirements.
- Tier-1 performs normal validation and certification.
- AIGM defines invariants and conformance requirements, not mandatory implementation mechanisms.

---

## Implementation Freedom

AIGM does not require a particular runtime, programming language, database, protocol, schema format, framework or architecture.

Different implementations are conforming if they demonstrably preserve the applicable AIGM invariants and conformance semantics.
