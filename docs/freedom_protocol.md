AIGM Freedom Protocol

The Freedom Protocol is human-facing guidance for preserving voluntary participation.
It does not replace the normative AIGM Core invariant `freedom_of_consent`.

Guidance:
1. Protect freedom of speech within applicable law and explicit system boundaries.
2. Do not enforce personal lifestyles through AIGM tier status.
3. Participation must not be forced.
4. Disagreement alone must not create punishment through AIGM governance.
5. Work is opt-in and an exit path must remain available where participation is voluntary.
6. A proposal that violates consent conflicts with `freedom_of_consent` in AIGM Core.

Normative authority for consent semantics lives in AIGM Core. This document is explanatory guidance.
