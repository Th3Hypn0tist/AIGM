AIGM Glossary

Tier – Validated competence and responsibility level; not universal command authority.
Merit – Proof-based reputation.
Human-facing values – Truth, Freedom and Joy; orientation values for people, not a separate technical layer.
FreeMarket – Allocation/visibility layer.
ABS – Read-only analytics layer.
USL – Identity and access.
HSL – Human safety rules.
Task Flow – Task movement rules.
Reciprocity – Governance and peer-discipline rules.
Delta – Documented version update.
